# Global Coding Style

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle global coding style.

## When to use this skill

- When writing any new TypeScript, JavaScript, or code files
- When refactoring existing code for better readability
- When naming variables, functions, classes, interfaces, or files
- When keeping functions small and focused on a single task
- When removing dead code, unused imports, or commented-out code blocks
- When applying the DRY principle to extract common logic into reusable functions
- When ensuring consistent indentation and code formatting
- When choosing meaningful, descriptive names that reveal intent
- When working with any code file in the project (frontend or backend)
