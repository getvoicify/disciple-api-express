# Global Tech Stack

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle global tech stack.

## When to use this skill

- When working with Express.js application setup, middleware, and routing
- When writing TypeScript code with strict type checking and modern syntax
- When performing database operations using PostgreSQL and the postgres client library
- When implementing caching with Redis using the ioredis library
- When validating request data with Zod schemas
- When handling JWT token authentication with JOSE
- When implementing structured logging with Pino and pino-http
- When writing tests with Vitest framework and Supertest for HTTP testing
- When handling file uploads with Multer or image processing with Sharp
- When integrating with cloud storage services (AWS S3 or Cloudflare R2)
- When generating API documentation with Swagger JSDoc
- When setting up development tools and managing dependencies in package.json
