# Global Validation

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle global validation.

## When to use this skill

- When validating user input in API endpoints (body, params, query)
- When creating Zod schemas for request and data validation
- When implementing server-side validation (required for all inputs)
- When adding client-side validation for improved user experience
- When sanitizing input to prevent injection attacks (SQL injection, XSS, command injection)
- When validating business rules and application constraints
- When providing clear, field-specific error messages to users
- When implementing type, format, and range validation
- When working with API endpoints, form handlers, or any code processing user input
