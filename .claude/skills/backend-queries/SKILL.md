# Backend Queries

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle backend queries.

## When to use this skill

- When writing SQL queries or database operations
- When implementing repository methods that query the database
- When using parameterized queries to prevent SQL injection
- When optimizing query performance with indexes and joins
- When implementing eager loading to prevent N+1 query problems
- When wrapping related database operations in transactions
- When adding query timeouts for long-running queries
- When implementing query result caching strategies
- When working with repository files, data access layer files, or any database operation code
