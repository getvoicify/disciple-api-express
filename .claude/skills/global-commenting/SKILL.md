# Global Commenting

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle global commenting.

## When to use this skill

- When writing new code that has complex logic requiring explanation
- When adding comments to clarify business rules or algorithms
- When ensuring code is self-explanatory through clear structure and naming
- When reviewing existing comments to ensure they're evergreen and still relevant
- When removing or avoiding comments about recent changes, temporary fixes, or TODOs
- When deciding whether code needs comments or if better naming would suffice
- When working with any TypeScript, JavaScript, or code file in the project
- When documenting why certain approaches were chosen, not just what the code does
