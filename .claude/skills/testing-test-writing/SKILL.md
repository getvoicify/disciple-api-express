# Testing Test Writing

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle testing test writing.

## When to use this skill

- When writing unit tests for services, repositories, utilities, or business logic
- When writing integration tests for API endpoints using Supertest
- When implementing Test-Driven Development (TDD) by writing tests before implementation
- When testing code that uses the safeExecute utility for error handling
- When mocking external dependencies (databases, external APIs, file systems, cloud services)
- When writing tests with clear arrange-act-assert structure using Vitest's describe/it blocks
- When testing both success paths and error cases
- When running code reviews on test code using the CodeRabbit CLI
- When working with test files (*.test.ts, *.spec.ts) in /tests/ or __tests__/ directories
- When ensuring test coverage for critical user flows and core business logic
