# Backend Models

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle backend models.

## When to use this skill

- When creating or modifying database model definition files
- When defining table schemas and column data types
- When establishing relationships between models (foreign keys, one-to-many, many-to-many)
- When adding database constraints (NOT NULL, UNIQUE, CHECK constraints)
- When choosing appropriate data types for model fields
- When adding timestamps (created_at, updated_at) and audit fields
- When implementing model-level validation rules
- When working with model files in `/models/`, `/entities/`, or `/schemas/` directories
- When deciding on normalization strategies for database design
