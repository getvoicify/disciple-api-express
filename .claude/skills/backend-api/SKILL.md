# Backend API

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle backend API.

## When to use this skill

- When creating or editing API endpoint files (typically in `/endpoints/`, `/routes/`, or `/api/` directories)
- When implementing Express.js route handlers for any HTTP method (GET, POST, PUT, PATCH, DELETE)
- When setting up input validation using Zod schemas for request body, params, or query parameters
- When extracting authenticated user information from JWT tokens in endpoints
- When implementing the handler factory pattern for dependency injection in endpoints
- When structuring consistent API responses with success/error formats
- When adding OpenAPI/Swagger JSDoc annotations to document API endpoints
- When working with Express middleware or request/response handling
- When implementing REST API controllers or handlers
