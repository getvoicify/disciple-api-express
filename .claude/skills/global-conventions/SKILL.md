# Global Conventions

This Skill provides Claude Code with specific guidance on how to adhere to coding standards as they relate to how it should handle global conventions.

## When to use this skill

- When organizing files and directories in the project structure
- When writing or updating README files and project documentation
- When creating commit messages, branch names, and pull/merge request descriptions
- When managing environment variables and configuration files
- When adding, updating, or removing project dependencies
- When implementing or following code review processes
- When using feature flags to manage incomplete features
- When maintaining changelogs or release notes
- When working with package.json, .env files, or project configuration
